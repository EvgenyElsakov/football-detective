# ⚽ Football Detective

ETL-пайплайн и аналитика футбольной статистики топ-5 европейских лиг (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1).

## 📊 Что собрано

- **7 096 матчей** за 4 сезона (2021/22 – 2025/26)
- **7 080 матчей с xG** — 99.8% покрытия
- **5 лиг:** Англия, Испания, Италия, Германия, Франция
- Источники: [FBref](https://fbref.com) (результаты) + [Understat](https://understat.com) (xG)

## 🛠️ Стек

- Python 3.14
- PostgreSQL 18
- SQLAlchemy + psycopg3
- soccerdata
- pandas

## 📁 Структура

| Файл | Назначение |
|---|---|
| `models.py` | Схема БД (таблицы `teams`, `matches`) |
| `load_season.py` | Универсальный загрузчик: любая лига, любой сезон |
| `research_1.py` | Расследование №1: общая картина «несправедливости» |
| `research_1b.py` | Расследование №1Б: разбивка по лигам, сезонам, командам |

## 🚀 Как запустить

1. Установить зависимости: `pip install -r requirements.txt`
2. Настроить подключение к PostgreSQL в `models.py`
3. Создать таблицы: `python models.py`
4. Загрузить сезоны: `python load_season.py 2324 2425`
5. Запустить расследование: `python research_1.py`

### 🎯 Миф 1: «Топ-клубы реализуют моменты лучше середняков»

**Вердикт:** 🟢 **Подтверждён** (p = 0.0044)

**Методология:** сравнили реализацию xG (голы / xG) у топ-8 клубов по суммарному xG за 4 сезона против остальных команд.

**Результат:**

| Клуб | Суммарный xG | Голы | Реализация |
|---|---|---|---|
| Bayern Munich | 379.4 | 407 | **107.3%** 🔥 |
| Manchester City | 326.4 | 339 | 103.9% |
| Arsenal | 311.9 | 319 | 102.3% |
| Inter | 321.6 | 328 | 102.0% |
| Paris SG | 338.3 | 336 | 99.3% |
| Real Madrid | 329.8 | 317 | 96.1% |
| Barcelona | 363.7 | 346 | 95.1% |
| Liverpool | 336.0 | 310 | 92.3% |

- **Топ-8:** средняя реализация **99.8%**
- **Остальные:** средняя реализация **92.7%**
- **Разница:** +7.1 п.п.

**Вывод:** топ-клубы действительно забивают больше, чем «должны» по xG. **Bayern Munich** — рекордсмен: 407 голов при xG 379 (перевыполнение на 28 голов за 4 сезона). Это объясняется классом нападающих и индивидуальным мастерством.

### 🏟️ Миф 2: «Домашнее преимущество слабеет из года в год»

**Вердикт:** 🟢 **Опровергнут** (p = 2×10⁻⁹⁷)

**Результат:**

|---|---|---|---|

**Вывод:** домашнее преимущество не только не слабеет, а остаётся **одним из самых стабильных факторов** в футболе. Разница между домом и гостевыми матчами сохраняется в диапазоне 20–32% на протяжении всех 4 сезонов.

### 🤝 Миф 3: «Топ-клубы чаще играют вничью»

**Вердикт:** 🟢 **Опровергнут (обратный эффект)** (p < 0.0001)

**Результат:**

| Категория матчей | Доля ничьих |
|---|---|
| Матчи с топ-8 клубами | **17.6%** |
| Матчи без топ-8 | **26.7%** |
| Разница | −9.1 п.п. |

**Вывод:** топ-клубы играют вничью **реже**, а не чаще. Логика простая: у них выше класс, поэтому они чаще выигрывают. Середняки, наоборот, предпочитают «сушить» игру — им важнее не проиграть, чем выиграть.

### ⏰ Миф 4: «Несправедливость сильнее в топ-матчах»

**Вердикт:** ⚪ **Не подтверждён** (p = 0.11)

**Методология:** определили топ-6 команд **внутри каждой лиги по каждому сезону** (по среднему xG). Сравнили долю несправедливых матчей в играх «топ-6 vs топ-6» и в матчах без топ-команд.

**Результат:**

| Категория | Матчей | Несправедливых |
|---|---|---|
| Топ-6 vs Топ-6 | 600 | **42.7%** |
| Без топ-6 | 3 289 | **46.3%** |
| Разница | | −3.6 п.п. |

**Дополнительно:**
- Суммарный xG в топ-матчах: **3.33** (vs 2.77 в матчах без топ-6, +20%)
- При более строгом «топ-4»: разница −6.5 п.п. (p = 0.058, тоже на грани)

**Вывод:** данные **не подтверждают** гипотезу. Наблюдается слабый тренд в обратную сторону — в топ-матчах несправедливость чуть ниже, но это различие статистически незначимо. Для строгого доказательства нужна большая выборка.

## 🎓 Что мы узнали

1. **Футбол несправедлив на 40.2%.** Каждый второй-третий матч заканчивается не по игре.
2. **Несправедливость универсальна** — разброс между топ-5 лигами всего 3%.
3. **Чем сильнее доминирование, тем честнее результат.** При разнице xG > 3 гола, команда выигрывает в 93% случаев.
4. **Топ-клубы реализуют моменты на 7% лучше** — это измеримое преимущество.
5. **Домашнее преимущество не слабеет** — стабильно 20–32% по xG.
6. **Топ-клубы не «сушат» ничьи** — они играют на победу и добиваются её.

## 🤖 ML-модель: прогноз исхода матча

Построили две модели прогноза на основе **предматчевой статистики** (форма команд за последние 5 матчей). Обучали на сезонах 2021/22 – 2022/23, тестировали на 2023/24 – 2024/25.

### 🎯 Модель 1: 3 класса (победа хозяев / ничья / победа гостей)

- **Accuracy:** 49.8% (против baseline 42.9%)
- **Прирост над baseline:** +6.9 п.п.
- **Признаки:** форма команды по xG и очкам за 5 матчей

**Главный результат:** ничья — **непредсказуемый исход**. Модель угадывает её в 1% случаев, что подтверждает фундаментальное свойство футбола: ничья не имеет чётких предматчевых признаков.

### 🎯 Модель 2: бинарная (победит хозяин или нет)

- **Accuracy:** **63.5%**
- **Baseline (мажоритарный класс):** 57.1%
- **Прирост:** **+6.4 п.п.**
- **ROC-AUC:** 0.674
- **Precision:** 58.9% (близко к букмекерскому уровню)

**Матрица ошибок:**

| | Пред. не победа | Пред. победа |
|---|---|---|
| **Ист. не победа** | 1464 ✅ | 513 ❌ |
| **Ист. победа** | 750 ❌ | 734 ✅ |

### 🎯 Важность признаков

| Признак | Вес | Значение |
|---|---|---|
| **`diff_form_xg`** | **+0.228** | Разница xG-формы — **главный предиктор** |
| `away_form_xg_for` | −0.168 | Сильная атака гостей мешает хозяевам |
| `away_form_xg_against` | +0.163 | Слабая защита гостей помогает хозяевам |
| `home_form_xg_against` | −0.148 | Слабая защита хозяев мешает им победить |
| `home_form_xg_for` | +0.144 | Сильная атака хозяев помогает |
| `home_form_pts` | +0.100 | Форма по очкам важна, но **вдвое слабее xG** |

### 💡 Главный вывод

**xG — более качественная метрика, чем результат.** Разница в xG-форме команд вдвое сильнее влияет на прогноз, чем разница по очкам. Это подтверждает основную идею проекта: **xG показывает истинную силу команды лучше, чем таблица**.
