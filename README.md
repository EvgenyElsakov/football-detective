# ⚽ Football Detective

ETL-пайплайн и аналитика футбольной статистики топ-5 европейских лиг.

## 📊 Что собрано

- **7 096 матчей** за 4 сезона (2021/22 – 2025/26)
- **7 080 матчей с xG** — 99.8% покрытия
- 5 лиг: Англия, Испания, Италия, Германия, Франция
- Источники: [FBref](https://fbref.com) (результаты) + [Understat](https://understat.com) (xG)

## 🎯 Ключевые выводы

1. **40.2% матчей несправедливы** — команда с большим xG не выигрывает. [Подробнее →](docs/research_1.md)
2. **3 из 4 футбольных мифов** опровергнуты данными. [Подробнее →](docs/myths.md)
3. **ML-модель предсказывает исход** с точностью 63.5% — близко к букмекерам. [Подробнее →](docs/ml_model.md)

## 🛠️ Стек

Python 3.14 · PostgreSQL 18 · SQLAlchemy · psycopg3 · soccerdata · pandas · scikit-learn · scipy

## 🚀 Как запустить

1. `pip install -r requirements.txt`
2. Настроить `DB_URL` в `models.py`
3. `python models.py` — создать таблицы
4. `python load_season.py 2324 2425` — загрузить сезоны
5. `python research_1.py` — запустить расследование
