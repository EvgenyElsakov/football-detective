# ⚽ Football Detective

ETL-пайплайн и аналитика футбольной статистики топ-5 европейских лиг (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1).

## 📊 Что собрано

- **7 096 матчей** за 4 сезона (2021/22 – 2025/26)
- **7 080 матчей с xG** — 99.8% покрытия
- **5 лиг:** Англия, Испания, Италия, Германия, Франция
- Источники: [FBref](https://fbref.com) (результаты) + [Understat](https://understat.com) (xG)

## 🛠️ Стек

- Python 3.14
- PostgreSQL 18
- SQLAlchemy + psycopg3
- soccerdata
- pandas

## 📁 Структура

| Файл | Назначение |
|---|---|
| `models.py` | Схема БД (таблицы `teams`, `matches`) |
| `load_season.py` | Универсальный загрузчик: любая лига, любой сезон |
| `research_1.py` | Расследование №1: общая картина «несправедливости» |
| `research_1b.py` | Расследование №1Б: разбивка по лигам, сезонам, командам |

## 🚀 Как запустить

1. Установить зависимости: `pip install -r requirements.txt`
2. Настроить подключение к PostgreSQL в `models.py`
3. Создать таблицы: `python models.py`
4. Загрузить сезоны: `python load_season.py 2324 2425`
5. Запустить расследование: `python research_1.py`

## 🔍 Расследование №1: «Насколько футбол несправедлив?»

**Гипотеза:** команда, которая создаёт больше моментов (xG), обычно выигрывает.

### 🚨 Главный результат

На **7 080 матчах** топ-5 лиг:

> **40.2% матчей закончились «несправедливо»** — команда с большим xG не выиграла.

| Ситуация | Матчей | % |
|---|---|---|
| Хозяева доминировали, но не победили | 1 642 | 23.2% |
| Гости доминировали, но не победили | 1 205 | 17.0% |
| **Всего «несправедливых»** | **2 847** | **40.2%** |

### 🏆 По лигам — разброс всего 3%

| Лига | Несправедливых | % |
|---|---|---|
| ESP-La Liga | 633 / 1520 | **41.6%** 🥇 |
| ITA-Serie A | 630 / 1519 | **41.5%** 🥈 |
| ENG-Premier League | 604 / 1520 | 39.7% |
| FRA-Ligue 1 | 507 / 1297 | 39.1% |
| GER-Bundesliga | 473 / 1224 | 38.6% |

**Несправедливость универсальна:** разброс между лигами — всего 3%. Это фундаментальное свойство футбола, а не особенность отдельного чемпионата.

### 📅 По сезонам — никакого тренда

| Сезон | Несправедливых | % |
|---|---|---|
| 2021/22 | 729 / 1826 | 39.9% |
| 2022/23 | 718 / 1751 | 41.0% |
| 2023/24 | 691 / 1752 | 39.4% |
| 2024/25 | 709 / 1751 | 40.5% |

Все 4 сезона — в диапазоне **39–41%**. Футбол не становится честнее или несправедливее — это стабильная константа.

### 🎚️ Сила доминирования определяет всё

| Разница xG | Матчей | Несправедливых |
|---|---|---|
| 0–0.5 (равные) | 2 059 | **60.3%** |
| 0.5–1 (лёгкое) | 1 772 | 46.7% |
| 1–1.5 (заметное) | 1 263 | 33.5% |
| 1.5–2 (сильное) | 847 | 24.6% |
| 2–3 (полное) | 836 | 15.0% |
| **3+ (тотальное)** | **303** | **6.9%** |

**Главный вывод:** если команда доминирует тотально (разница xG > 3 гола), она выигрывает в **93% случаев**. Футбол «несправедлив» в основном на тонкой грани — когда разница в моментах минимальна.
